# AI总说废话？装这个技能🤯

最近挖到一个项目，专治AI啰嗦。

i-have-adhd，一个给编码助手用的技能，核心一句话：把答案顶到最前面。

它火得有点离谱。HN 上那条 «I-have-ADHD: A skill to stop coding agents from burying the answer» 拿了 535 分、370 条评论（news.ycombinator.com/item?id=49610631）。大家是真受够了「Great question! Let me think about this...」这一套。

为什么叫 ADHD？不是让你去确诊。README 原话：ADHD-friendly outputs. No ADHD diagnosis needed! 灵感来自《The Adult ADHD Tool Kit》这本书，但改的是 LLM 该怎么回你，不是人该怎么过日子。

怎么用？复制这段丢进 CLI：
Install the i-have-adhd skill/plugin from https://github.com/ayghri/i-have-adhd, refer to the repo's AGENTS.md for instructions.

规则就 10 条，写在 skills/i-have-adhd/SKILL.md 里。挑几条感受下：先给下一步动作、多步任务编号、每轮复述当前状态、错误平铺直叙、列表最多 5 条、不许有开场白和结尾客套。

对比 README 里的 Before/After：以前是一大段「看起来 verifyToken 用了个旧 API……希望有帮助！」；装完之后直接 `npm install jsonwebtoken@latest`，然后改 src/auth.ts:42，三步编号，最后一句「测试挂了就把第一行错误贴过来」。

想自己改也行。fork 下来编辑 SKILL.md，然后：
claude plugin uninstall i-have-adhd
claude plugin marketplace remove i-have-adhd
claude plugin marketplace add <你的用户名>/i-have-adhd
claude plugin install i-have-adhd@i-have-adhd
重启 Claude Code，再 /i-have-adhd 调起来。

适合谁？每天被 AI 小作文淹没、只想拿答案就走的程序员。不适合谁？喜欢 AI 陪你聊天、要情绪价值和长篇解释的人——你会觉得它冷冰冰。
