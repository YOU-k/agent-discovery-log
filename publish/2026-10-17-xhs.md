# 拆解 Jevcrawl：为 AI 代理设计的无 LLM 爬虫

AI 代理抓外部信息，一般靠搜索接口或直接扒网页。搜索摘要不够看，整页丢给大模型又太费 Token。[RayenMlayeh/jevcrawl](https://github.com/RayenMlayeh/jevcrawl) 想解决这个痛点。

项目 README 拉取失败了，没法看安装命令、文件结构或 scripts/tests/CI。好在追踪数据和公开讨论里透出了机制。作者在 Hacker News 的 Show HN 讨论里说得很清楚，Jevcrawl 是 "a web crawler for AI agents with no LLM in the crawl loop"。也就是说抓页面不用大模型，靠传统代码硬抠。这就对上了“为AI设计的精准低成本网页爬虫MCP”的定位，把抓取阶段的 Token 省了下来。

没看到文件结构和测试用例，很难说这项目工程含量多深。它更像针对特定痛点的功能工具，用 MCP 把精简后的网页喂给 AI 代理。算不算严肃工程，得等代码库公开了再看。

MCP 生态里项目方向挺杂。[K-Dense-AI/claude-skills-mcp](https://github.com/K-Dense-AI/claude-skills-mcp)（407）以前做科学 skill 检索，因为主流 agent 自己支持了，现在停更；[arjun988/blender-skills](https://github.com/arjun988/blender-skills)（341）死磕 3D 美术，塞了 94 个 Blender 建模技能。别的还有 [yctimlin/mcp_excalidraw](https://github.com/yctimlin/mcp_excalidraw)（2,547）和 [openai/mcp-extensions](https://github.com/openai/mcp-extensions)（1,082）等。jevcrawl 则是盯住信息源头，靠精准爬取省 Token，适合需要去文献网页查资料的普通程序员。

目前星数低（77），网上讨论不多。不用 LLM 解析确实省钱，但碰到结构复杂的动态网页，提取准确率到底怎样不好说。README 缺失，抓取规则通不通用也没法验证。

AI 代理工具链在补齐，把成本控制卡在抓取这一步，挺务实。
