# 拆解FigureOneLab：复现论文Figure 1练计算生物学

计算生物学入门有个老问题：课上学的是怎么跑流程，可真到论文里，Figure 1 那一步得你自己从原始数据开始，判断该用什么方法，该信哪个结果。GitHub 上有一批项目想补这段空白，deanslee/FigureOneLab（276）就是其中一个，也是我们追踪列表里定位最特殊的一个。

按项目自己的说法，F1L 让人通过“重新演绎”现代生物学论文的 Figure 1 来练计算生物学。作者 Dean Lee 是 Novartis 的计算生物学首席科学家，他在 LinkedIn 上提过，自己当年是靠一个叫 Shannan 的人帮了个小忙才进了这行，现在做这个项目算是把这份帮助传下去（来源：Dean Lee 的 LinkedIn 帖子）。他还办了一份叫 Figure One Lab 的 newsletter 发项目进展（来源：YouTube 访谈“How to become a computational biologist in a year”）。Caroline Rende 在 LinkedIn 上称它是“构建计算生物学作品集”的新项目。这些背景能看出来，它想造的不是工具，是训练材料。

拆它的实现方式之前得先说一件事：这次 README 正文没抓到，所以具体命令、文件结构、scripts、CI 配置都引用不了。能确认的只有项目自述的功能定位——让用户复现论文 Figure 1。那对它的“工程含量”就得留点余地：从现有证据看，它更像一套拿论文数据和论文方法当素材的训练资源合集，不太像一个带完整工程链路的软件项目。有没有测试、有没有持续集成、代码是脚手架还是提示词包装，缺了 README 都下不了结论。这本身就值得记一笔：一个星数快三百的项目，README 都抓不稳，至少说明文档维护不算重。

放到科研栈里看更清楚。我们追踪的同类项目多是科学技能库，形态是工具——给函数、给接口、给能调用的能力；FigureOneLab 直接给论文数据加论文方法，让你动手重做一遍。前者回答“我可以用什么”，后者回答“我能不能独立做完这一篇”。所以我们给它的复现契合度是 10/10，重复度标注为无重复：追踪数据里没有明显同类项目。它适合两类人：想练手但缺真实材料的学生，以及想在论文里找选题方向的研究者。如果你要的是一个能直接调用的生信工具库，它帮不上忙。

局限也明显。训练效果很依赖所选论文的质量和可复现程度，项目本身不保证每一篇 Figure 1 都能顺利重做；没有公开的测试和 CI，意味着它没法像工具项目那样验证正确性；README 抓不到也说明文档可能不是它的重心。一个开放问题是：这种“复现型”资源怎么规模化——靠作者一个人选论文，能覆盖多少方向。

它的价值不在代码写得多好，而在于把“从论文到能力”这条路铺成了能直接走的形式。
