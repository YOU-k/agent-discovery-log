# 拆解 anything2explainer：主题进，讲解视频出

过去一年，GitHub 上冒出一批想自动做内容的项目，大多停在提示词模板那一层。今天聊的这个，算里面星比较多的。据 SkillsLLM 收录页面，anything2explainer 是个开源 skill，给 AI 编程助手用，适配 Claude Code、Codex CLI、ChatGPT 这些，定位就是"你给个主题，它输出带配音的讲解视频"。截至追踪数据，1,986 星，9 月 10 日第一次被记录，一天涨大概 108 星。它解决的事很具体：把"讲清一个概念"从写脚本、分镜、配音、字幕到渲染的整条链子，压成一次对话。

怎么做的。据它 GitHub 仓库描述，输出是一条完整流水线，研究、解说词、分镜、镜头代码四步，配音走 TTS，字幕做了逐词对齐，语言支持中英文。重点是渲染方式：每一帧用 Remotion 以代码绘制，不是生成像素。仓库还列了常驻图层，44px 白字黑描边字幕、底部章节进度条、顶部胶囊 HUD、可选的流程轨道，片尾有"built by Anything2Explainer skill"署名（builtBy 字段设成空字符串就能去掉）。所以视频不是"生成"的，是代码画出来的。

工程含量上，有真东西，不是提示词套壳。三个依据。一，产出是可复现的代码帧，Remotion 是程序化视频框架，画面元素由参数和组件决定，不靠模型采样，这意味着得有真的组件和时间轴代码。二，字幕做了词级对齐，字号、描边、位置都写死了具体数值，这种约束一般来自渲染层的实际实现，不是文案里写写。三，它被明确定义成 skill，还声明兼容 Claude Code 和 Codex CLI 多个宿主，说明有围绕代理调用的接口约定。得说一句，我们抓 README 失败了，上面这些来自仓库公开描述和第三方收录页，scripts、tests、CI 配置这些细节暂时核不了，所以工程判断停在"确认为实现层项目"这一级。

横评。素材里唯一能比的同类是同一作者名下的 video-shotcraft（线索在 Threads 帖子里提到的仓库链接），两边部分重叠，差别在定位：video-shotcraft 覆盖面更宽，涉及产品类视频，anything2explainer 专攻讲解动画，不碰产品片。要是追踪数据里没更多同类，那它现在更像这个细分方向上的单点项目，不是拥挤赛道里的一员。

开放问题也有几个。一，它的成败取决于上游模型的研究和脚本质量，渲染只是下游，它自动化的是工序，不是内容判断。二，日增 108 星的速度跟仓库公开信息的完整度对不上，README 抓取失败本身就是个信号，文档和代码成熟度是否跟得上热度，得实际装一遍才知道。三，Remotion 代码帧可控，换来的稳定，代价是视觉上限被组件库框住，风格灵活性有天花板。

它更像一台把主题翻译成代码动画的编译机，不是会讲故事的创作者。
