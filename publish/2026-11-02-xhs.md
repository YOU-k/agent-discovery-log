# 拆解 huashu-design：可交付设计的本质

过去一年 AI 生成代码和文本已经很能打了，但视觉设计这块还是不太行。大模型直接出的页面通常排版混乱，风格也不统一。GitHub 上冒出来几十个想解决这个问题的项目，今天聊的 alchaincyf/huashu-design 是星数最高的之一，目前标星 28401，日均涨星 276。宣称一句话就能生成可交付的 PPT、网页或信息图。

看 README，通过 `npx skills add alchaincyf/huashu-design` 安装，兼容 Claude Code 等多个 Agent。不只是调提示词——三套逻辑各出两个候选，六个缩略图给你挑。里面有个 `scripts/ref_board.py`，网络资料说这个脚本会先截参考作品的图，让 Agent 先看图再拆解。还带设计体检和外观账本，记录最近交付的风格特征做撞车检查。

一个 skill 到底是套壳还是有真活，看代码和流程就行。Huashu Design 的 `scripts/ref_board.py` 加上自动化的核查和设计体检，有真实工程量在里面。它要求 Agent 提取参考板，还要校验抓取的图是不是公共领域或免版权。视觉素材获取和一致性这块做了约束。

同类项目各有各的定位。sunchaokun/PPT-Design-Skill 专攻 PPTX；bendrape1-byte/silk-design 专做网页动效；abdiraimov-otabek/dashboard-design-skill 专精数据看板。Huashu Design 覆盖面更杂，从网页、App 原型到 PPT 和信息图都管，风格库扩到 84 种，适合要多媒介快速交付的人。

但也有坑。网络资料提到目录名冲突，内置轻量版不能跟独立仓库完整版同时装，得手动改名。SourceForge 镜像信息显示早期描述里有对话脚本优化之类的定义，如今转向视觉设计。实际生成质量嘛，还是看底层模型理解力。

Huashu Design 把设计意图转成可交付资产做了一次工程化尝试，可以拿来做效率工具试试。
