# 拆解 schematic-figure：AI画科研示意图

科学论文里画示意图太费时间，大模型一直不太擅长。lgwrightlab/schematic-figure 就是来干这个的。作者 Logan Wright 是耶鲁助理教授，他们实验室搞量子信息和物理启发的机器学习，平时少不了画复杂示意图。这项目就是给 AI 代理补上画出版级科学示意图的技能。

这次 README 没抓到，看不到具体的命令、文件结构、scripts 或 tests/CI 这些细节。看 GitHub 描述和 LGW Lab 博客的说法，它是一个开源 skill，让大模型直接生成矢量代码来画 SVG 和 PDF 格式的示意图，效果差不多能到出版质量。

没看到代码结构、测试和 CI 配置，这项目目前更像一个针对特定任务的提示词和技能包装。基本靠大模型原生代码生成能力画图，没看到什么深度的独立工程化封装。

同类项目里，schematic-figure 专攻科学示意图。这跟 deanslee/FigureOneLab 拿论文数据做计算生物学训练不一样，跟 ythx-101/live-panel-skill 画动态架构图也有区别。至于 zarazhangrui/codebase-to-course 做交互课程和 xianyu110/ecommerce-video-skills 搞电商视频，方向差得更远。

缺少详细 README，普通人很难评估部署稳不稳定、好不好维护。而且大模型画出来的矢量图到底能不能真正符合学术规范达到出版级，也得打个问号。

做科研绘图挺实用，但工程深度确实还得再看看。
