# 拆解 cli-faq-shortcuts：长指令的自动化捷径

代码库变大，发给 AI 编码代理的请求越来越长，每天重复敲同样的指令挺烦人的。GitHub 上最近出了个新项目 kishormorol/cli-faq-shortcuts 想解决这事。作者在 LinkedIn 说，这工具能读取你在 Claude Code、Codex 和 Cursor 里的历史记录，直接转成能复用的斜杠命令。

README 写得很清楚，git clone 后软链接到 `~/.claude/skills/faq-shortcuts` 就能装好。敲 `/faq-shortcuts` 命令，`scripts/extract_asks.py` 这个提取器就会去扫本地项目历史，支持用 `--since` 或 `--source` 过滤。生成的短命令存在 `.claude/skills/<name>/SKILL.md` 里。里面不光有查询指令，还带了 `Traps`（历史踩坑记录）和 `Report` 规则。项目顶端挂着 GitHub Actions 的 Tests 徽章，起码有基础 CI。

这不是套壳提示词。提取器只用了 Python 标准库，不需要 API 密钥也不联网，意图分组全在本地跑。README 里给了完整文件结构和独立调脚本的例子，也用 awk 和 wc 统计过，一个真实项目里精确字面重复只有 4 次，但按意图分组后重复高达 127 次。这种模糊匹配的思路挺有工程意识。加上纯标准库实现和测试覆盖，算是有真东西的。

横向看几个同类工具，路子不太一样。HKUDS/CLI-Anything 是让 AI 操作软件，zarazhangrui/codebase-to-course 把代码库转成课程搞知识传递，ythx-101/live-panel-skill 把配置转成动态架构图做可视化，还有 glitternetwork/pinme 专注一条命令部署全栈。cli-faq-shortcuts 比较垂直，专门挖个人工作流历史沉淀快捷命令，适合经常重复敲特定业务查询的程序员。

当然缺点也有。意图分组质量直接看底层大模型的脸色，容易波动。而且只原生支持 macOS 和 Linux，如果你平时请求没什么规律性重复，用它收益不大。整体看，算是个把个人隐式工作流转成显式资产的小尝试。
