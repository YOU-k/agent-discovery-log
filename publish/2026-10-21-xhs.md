# 拆解 agent-vision-toolkit：纯文本模型如何看图

用纯文本模型跑 Agent，最大的麻烦就是看不了图，调工具还老被拦。GitHub 上有人盯上了这个需求，想给纯文本模型加双“眼睛”。

Anionex/agent-vision-toolkit 截至8月底有 1,242 星，日均涨 2 个。它给了两套东西：一套是 CLI 工具和对应技能，另一套是可选的透明本地代理跟单文件原生插件。看 README，`extensions` 和 `bin` 目录底下放了 Shell 脚本，只要 Agent 能跑 shell 就能接。思路是把模型想看图的意图提出来，再还原它要看图的原因。作者说代码都在 Codex 和 DeepSeek 真实跑过，Claude Code 和 Pi 也做了端到端实测。

这不是丢个提示词模板就完事。它确实给到了跨平台代理、`bin` 里的 Shell 脚本，还把提取视觉意图那套机制做出来了。作者 anionex 本身跨项目星超 16k，上过 GitHub 开发者热门榜第三。针对特定平台还有定制分支比如 dsh-vision-toolkit，不是纸上谈兵。

对比同星量级的 soumatheusgomes/vibe-coding-toolkit（1,850星），后者偏向给文档、提示词、模板配环境，走的是工作流引导。agent-vision-toolkit 更实一点，直接干视觉处理的活。要拿纯文本模型读论文看图、做前端还原或者 GUI 自动化，用这个更顺手。

缺点也很明显，重度依赖代理集成和外部工具调。模型本身推理不行，表达不出视觉意图，这工具也就跟着拉胯。无缝集成现在是个可选升级，放到别的非原生纯文本模型上会不会水土不服，还不好说。

工具补上了看图这环，但能看多准，终究还是看底层模型能把意图说得多明白。
