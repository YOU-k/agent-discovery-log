# 拆解 OpenClaw：医学AI技能库的本质

通用大模型做医学应用，往往知识太泛，连不上真实数据库，也没有标准流程。医学研究得查 PubMed、跑 RNA-seq 流程，光靠写提示词干不了这些活。OpenClaw-Medical-Skills 就是来管这事的。到 2026 年 9 月初这个项目记录有 3080 颗星，看 SourceForge 镜像和 Reddit 讨论区，它在 OpenClaw 生态里是个关注度挺高的医学技能库。

它把 869 个医学技能拆成单独的 SKILL.md 文件，管临床也管基因组学。用之前得先装好 OpenClaw 或 NanoClaw 框架，然后 git clone 加 sparse-checkout 拉代码，把 skills 目录拷到工作区或者 ~/.openclaw/skills/ 下。有些技能挂着大文件，README 里劝大家用 sparse-checkout 避免下载数据量太大，不然就配 Git LFS。

看代码就知道，这东西就是提示词包装出来的技能包声明，算不上底层系统软件。仓库里没测试脚本，也没 CI 配置，核心东西全是从 12 个开源技能仓库聚合来的结构化指令集。它自己跑不起来，得靠 OpenClaw 框架解析 SKILL.md 去调真实 API 和数据库。

跟同类项目比，路子不太一样。wilbert-MD-PhD/medical-illustration 专门做医学图表生成，带画图技能和验证工作流。OpenClaw-Medical-Skills 面铺得更广，支持 SOAP 笔记、VCF 注释这些临床和基因组学功能。但它偏临床，没完整的单细胞测序流程。想快速调医学数据库、生成标准文档的临床人员用着挺合适。

毛病也有。它跟 OpenClaw 绑得太死，离开这个生态，技能文件也就只能当参考文本看看。另外指令集是聚合来的，实际跑的时候很可能遇到外部 API 挂掉或者数据合规风险，开源医学工具一直都有这问题。

说白了它是个医学 AI 技能索引库，拉低了调用专业工具的门槛，但重活儿都让宿主框架干了。
