# 拆解 PPT-Design-Skill：Claude Code 时代的演示文稿工程

AI 生成 PPT 总是有点尴尬，吐出来的 HTML 或图片没法直接拿去正式场合用，排版也没法二次编辑。习惯命令行的程序员更想要能输出原生 PPTX 还能接进现有代码工作流的东西。sunchaokun/PPT-Design-Skill 就是冲这个做的一个 Claude Code Skill。

看实现，它有明确的模式分发。GitHub 上写明 FreeStyle 模式包含 `generate_ppt(query=...)` 和 `generate_ppt(content=...)` 两种输入，其实底层是同一个生成引擎，只是接口不同。交付流程强制要求正式交付前过一遍 PNG 视觉检查。工程文档里也给了具体决策：拿不准就用 Build Mode，图快或者必须套现有模板才用 FreeStyle 或 VI Build Mode。

所以这不只是套层提示词。模式选择、强制视觉检查，加上输出完全可编辑的 PPTX，有实打实的工程含量。

横向看同类 Skill，定位差挺多。dominikmartn/nothing-design-skill 只做网页风 UI，风格单一；bendrape1-byte/silk-design 专心搞动效和滚动手感；OpenLabs-so/oa-design 主攻数据看板类前端 UI。做 PPT 这块，carnot-tech/consulting-pptx-skill 更偏咨询级规范和机器检查，而本项目专攻视觉设计，内置 4 万风格库。

不过截至 2026 年 8 月底，这项目日均涨星大概 16 个，社区规模还比较小。另外，FreeStyle 和 Build Mode 怎么切换很看个人经验，庞大的风格库长期维护起来稳不稳定，也不好说。

AI 生成演示文稿正从文本拼凑转向工程化交付，这类工具算是提供了一个严谨的过渡样本。
