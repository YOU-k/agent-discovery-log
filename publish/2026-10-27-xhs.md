# 拆解 cvpr-paper-playbook：科研论证还是提示词包装

AI 辅助科研工具现在大多只能改改字句。CV 领域不一样，论文能不能中，实验设计和论证逻辑才是关键。GitHub 上新出的 cvpr-paper-playbook 想解决这个，把研究问题、主张、实验和图表串成一条论证链。

这是个面向 CVPR 及相近视觉会议作者的 Claude Code skill。仓库里 SKILL.md 是入口，references 目录分了 writing、experiments、figures 几个工作说明。安装只要 Python 3.9+ 标准库，跑 python3 scripts/install.py 就行，不联网也不用 API key。它不直接算录用概率，只给四档评估，从“证据不足以判断”到“具备竞争力”，逼着作者分清哪些是论文没做的工作，哪些是自己没提供的材料。

项目不是简单套个提示词。里面有 scripts 管安装和版本覆盖，也有 tests 目录。跑 python3 scripts/validate.py 和 python3 -m unittest discover -s tests -v 能自动检查格式、内部链接、可移植性这些。docs 目录还记录了三篇正式论文的规则复核和独立代理的合成行为检查。

看同类项目，lishix520/academic-paper-skills 偏重多轮验证和审稿模拟；Boom5426/Nature-Paper-Skills 针对期刊投稿，看重证据边界和图注统计。cvpr-paper-playbook 钻得更深，专搞“论证逻辑”和“实验设计”。那个主张—证据矩阵就是给 CV/ML 场景定制的，没硬套 Nature 的跨学科标准。

GitHub 页面写得很直白，规则是从一些 CVPR 阅读案例里挑出来的，没跑过三年全量论文统计，没做真实录用预测校准。作者也强调这东西就是给作者自查的，正式受托审稿得按会议当年的保密和 LLM 规矩来，替不了正式 review。

工具能帮着理清论证流程，但科学上的判断最后还是得研究者自己定。
