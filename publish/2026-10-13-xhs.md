# 拆解 harness-anything：AI 如何接管本地办公软件

大模型想控制本地桌面软件挺难，尤其是WPS、Zotero这种没开放API的。yb2460/harness-anything 这个项目就是干这个的。2026 年 9 月初发现的，目前有 2262 颗星，日均涨 15 颗。它算是给AI控制办公软件搭了座桥。

主仓库 README 拉不下来，只能看 CONTRIBUTING.md 和技能页。其实它就是个命令行工具，靠 WPS 的 COM 自动化接口，用 pywin32 库去操控 Writer、Calc 和 Impress。代码里调用了三个 COM ProgIDs，比如 `KWPS.Application` 指向 WPS Writer。TypingMind 那边的技能描述说，它能基于 JSON 数据驱动生成 PPT，命令行也能控制文字表格和演示文稿。

这项目有真实代码支撑，不是纯提示词糊弄的。封装了 pywin32 的 COM 接口，又加了一层命令行调用。不过 GitHub Issues 里有人反馈“cli-anything-powerpoint安装失败”，而且 Issue 也不让随便建。估计工程化测试和 CI（持续集成）还没搞太完善，普通用户配环境会有点费劲。

看了下 SkillsLLM 的对比数据，它比 n8n 或 hermes agent 这种通用工具更专注本地办公套件。办公自动化这块，它比 genoffice 更懂中文场景和 Zotero；跟 zLanqing 的 office-academic-skill 比，Office 操控能切得更细，但功能重叠度挺高。

最大的硬伤是平台限制。COM 自动化只能在 Windows 上跑。开发者虽然弄了个 harness-anything-mac 分支，想拿 LibreOffice headless 模式在 macOS 和 Linux 上平替，但跨平台的指令能不能对齐、排版还原度怎么样，现在还不好说。

整体看，harness-anything 给大模型控制本地封闭软件提供了个不错的 Windows 思路。只是跨平台体验还得再打磨。
