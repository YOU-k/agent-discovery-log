# 拆解 easyplot：科研作图技能的工程边界

画出版级别的科研图表向来麻烦，配色排版和导出预检特别吃时间。这周看的是 Rimagination/easyplot，想用 Claude Code 技能把科研作图和导出这块弄简单点。

但这个项目 README 抓不下来，所以没法看它具体怎么调命令、文件长什么样，有没有写 scripts/tests/CI 也不清楚。网上信息显示它主要拿来看数据、画图，能调颜色主题，还能画交互散点图找异常值。看了看作者另一个项目 Rimagination/h3lite，连 SECURITY.md 都没配，基础工程配置估计比较弱。

我觉得它更像是个提示词包装或者说明文档，算不上有独立测试流程的真实工程。它就是把科研作图规范和导出预检的逻辑包成了大模型能调用的技能，主要靠底层模型写代码，本身没做什么软件工程化的事。

同类技能包侧重点都不太一样。zarazhangrui/codebase-to-course（5,603）把代码库变成能滚动学的 HTML 课；wilbert-MD-PhD/medical-illustration（163）专门画带审核记录的医学插画；viettranx/3dviz-pro-max（580）做的是 Three.js 和 Blender 三维可视化；tradermonty/claude-trading-skills（2,909）看名字就知道是搞股票和 ETF 复盘的。easyplot 比较专，只管二维科研作图的配色和预检。

没看到测试用例，换台机器跑稳不稳很难说，出图好不好看完全看模型写代码的发挥。

急着画规范图表的学者可以拿来当个趁手工具降低门槛，但现在离成熟软件还差得远。
