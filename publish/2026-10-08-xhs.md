# 拆解 Claude Code Paste Preview：终端图像标注的实现

终端里用 AI 编程助手，贴图预览一直挺难用的。同类项目里终端图片批注几乎是空白。alan890104/claude-code-paste-preview（星数 27）填了这个坑。

看 README 和 HN 上的 Show HN 帖子，往 Claude Code 贴图时会弹出一个图像编辑器。快捷键挺多：P、O、B、A、T 分别是画笔、椭圆、框选、箭头和文本；C 键裁剪，选区拖完按 Enter 确认；R 键转 90 度；数字键 1 到 7 换颜色。撤销也支持，macOS 用 Cmd+Z，Linux 和 Windows 是 Ctrl+Z。

这不是简单的提示词包装，真做了工程实现。终端外套了层跨平台 GUI，把键盘事件和图像处理绑在一起，绕过了终端纯文本没法操作像素的限制。macOS、Linux 和 Windows 都能跑，底层差异应该处理得还行。

追踪列表里另一个项目 lowenbjer/claude-terse（星数 15）在做精简回复，这个专攻图像标注。要是你经常看科研图需要标注，或者总得跟 AI 描述局部细节，用这个挺合适。

Builder.io 博客提过 Claude Code 预览本质是本地单人优先的，处理 monorepo 有限制。这工具发到 HN 后还没人评论，复杂终端环境下的稳定性和终端模拟器兼容性都得再看看。

缺的交互是补上了，但实际能用到哪一步还得看你的工作流。
