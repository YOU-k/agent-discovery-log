# 拆解 Science Skills：是真实工程还是包装

最近 GitHub 上冒出不少科研 agent 技能库。通用大模型在科研里不接专业数据库，每次调外部数据都得烧一堆 token 拼上下文。Google DeepMind 的 science-skills 想用工程手段搞定这个 grounding 问题。

2026 年 Google I/O 当天开源，直接塞进 Google Antigravity 平台。GitHub 页面说这是一套科研 agent 技能，涵盖基因组学、结构生物学、化学信息学和文献检索。技术报告提到 DeepMind Science 团队内部测过，主要做生物学和生命科学。里面接了 AlphaGenome、AFDB、UniProt 等 30 多个数据库和工具。

没拿到完整 README，不知道有没有 CI 流水线或测试目录。现有信息看，技能是用代码封装的，不是纯文本提示词。IntuitionLabs 评测说仓库有代码把几十个生命科学资源串起来，README 也强调优化 token 效率，这确实得写接口。但没看到可验证的测试和脚本结构，不好评估工程深度。感觉有真实接口工程，不是拿提示词套壳，但完整度还得再验证。

横向看，jaechang-hits/SciAgent-Skills（369 星）和 cookjohn/wos-skills（120 星）都是这项目的克隆或衍生。LeonChaoX/qinyan-academic-skills（930 星，评分 8/10）走广度路线，187 个技能连基金申请和临床都管，单个深度估计够呛。growthenginenowoslawski/coldoutboundskills（736 星，评分 3/10）是纯商业外呼，跟科研不搭边。Science Skills 胜在官方背景，跟 AlphaGenome、UniProt 整合得深，就是技能数量没社区项目多。

当前版本死磕生命科学，化学和材料还没管。Hacker News 上有个讨论说“数据科学技能缺口本质上是招聘和管理问题”（Hacker News, item 14651480、14698831），有点意思。工具能补技术差，但组织结构上的毛病治不了。这个项目在 HN 上热度极低，社区认知还在早期。

总结：官方做的，有实打实的接口适配工程，死磕生命科学。在科研 agent 技能库里算靠谱的，就是广度和社区活跃度还得再看看。
