# 拆解 consulting-pptx-skill：PPT 生成的工程化实现

GitHub 上出现了数十个做 AI 生成 PPT 的项目。多数工具只是文本转图像，缺专业排版逻辑，达不到咨询机构或董事会的标准。今天深扒的 carnot-tech/consulting-pptx-skill 走了另一条路。项目自 2026 年 9 月首次发现以来日均涨星 28，目前总星数 818。

仓库描述写了三个核心组件：约 110 项幻灯片设计规约、62 型 HTML 零件集（基本 27 种加追加 35 种）以及规约违反机械检查脚本。实际跑起来，模型先加载成文规约，用 HTML 零件拼幻灯片，最后触发脚本验证结果合不合规。YouTube 上关于 Claude Web Skills 的讨论也提到，做这类技能得带上工作流。这个项目就是把工作流写成了代码规约。

看工程量就知道，这不是套个提示词就完事的项目。技术门槛在规约和执行分离：把设计规范变成代码，用检查脚本自动卡大模型的结果，而不是纯靠模型概率生成。

同类项目定位差别挺大。sunchaokun/PPT-Design-Skill 重视觉，拿 4 万风格库生成可编辑 PPTX，适合看重表现力的人。consulting-pptx-skill 强调规范约束和机器检查，偏严谨咨询风。gozen3ji/consulting-pptx-skill 跟本项目几乎一样，疑似 fork，二选一就行。

它的问题也明显。高度依赖 HTML 零件拼接和规约检查，碰上非标准排版可能不够灵活。规约脚本能覆盖多少排版异常，现在还不好说。

拿规则和脚本卡大模型，算是让 AI 产出专业文档的实在路子。
