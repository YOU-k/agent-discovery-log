## [score 8/10] [fit 6/10] ordewell/ordewell  ·  ★88

- **类型**: 多智能体框架
- Multi-agent task orchestration for coding agents. Turn one goal into an ordered plan of tasks — each with its own runner, model and mode — then execute and verify the results.
- **是什么**: 把一个大目标拆成有序任务清单，每个任务配不同模型和执行方式，跑完自动验收
- **能做什么**: 把科研大流程（数据下载→预处理→建模→出图→写报告）拆成多步骤 agent 流水线
- **大家怎么用**: 在终端输入目标，规划器读仓库生成任务计划，逐条执行并验证结果
- **举个例子**: 在终端敲一句「把这份10x数据跑完QC+聚类+标记基因」，它排出7步计划，每步指定模型，自动跑完并报告哪些步通过
- **和已有项目比**: 和 AutoAgent、swarms 相比更偏「先规划后执行+逐步验证」，适合有序流水线而不是自由对话式协作
- **重复情况**: 和 open-multi-agent、Shannon 部分重叠，它多了计划审核和每步验收

## [score 7/10] [fit 5/10] andreylukin/bough  ·  ★9

- **类型**: 工具
- A terminal coding agent where the model writes one program instead of calling tools one at a time.
- **是什么**: 终端写代码 agent，模型直接写一段程序干活，而不是一次调一个工具
- **能做什么**: 让 agent 一次写完「改脚本+跑生信流程+看结果」的多步动作，省来回
- **大家怎么用**: 在终端里给任务，模型写 JS 块调用文件/命令/MCP 工具，跑完把输出回传再决策
- **举个例子**: 让它修一段出错的 scanpy 脚本，它一个回合里改文件、跑测试、看 diff 全搞定
- **和已有项目比**: 和常见工具调用式 agent 不同，把工具当函数放进一段程序里跑，能分支判断省轮次
- **重复情况**: 无重复
- **装不装**: 观望：玩法新但只 Go 生态、小众
